# Milestone Handoffs

Each milestone gets a handoff file at:

```text
docs/milestones/<milestone>_handoff.md
```

Each handoff must document:

1. Files created or modified.
2. Files intentionally not touched.
3. Commands/checks run and results.
4. Deviations from `docs/v1_3_1.md`, if any.
5. Known limitations.
6. Exact next step for the next milestone.

New Codex sessions should read `AGENTS.md` and the previous milestone handoff before writing code.
